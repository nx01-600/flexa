# Flexa — visual prototype

Non-functional prototype of Flexa (earned wage access). Two surfaces:

- `/app` — worker app (mobile, 430 px column)
- `/empresas` — Flexa Empresas (desktop)

All data is simulated in `lib/mock.ts`. Design tokens live in `app/globals.css`.

```bash
npm install
npm run dev
```

Stack: Next.js 16, Tailwind CSS v4, shadcn/ui (Base UI), Motion, Recharts, Lucide.
